# ADR-0001: Record architecture decisions

- Status: accepted
- Date: {{date}}

## Context
We need a lightweight, reviewable record of significant decisions for {{project}}.

## Decision
Record decisions as numbered Markdown files in `docs/architecture-decisions/`.

## Alternatives considered
- Wiki pages (drift from code, not reviewed with changes)
- No records (decisions get re-litigated)

## Consequences
Each significant decision adds a short file reviewed like code; superseded records are
kept and linked.
