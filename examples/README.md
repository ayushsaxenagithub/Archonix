# Examples

Everything here is **synthetic** and exists to demonstrate and test Archonix. None of it
is production code; credentials are fake and deliberately obvious.

| Path | What it shows |
|---|---|
| `python-service/` | Flask-style service with deliberate Bandit, Ruff and Vulture findings, pytest tests, an OpenAPI file and a Dockerfile |
| `ts-web/` | Next.js/React + Prisma TypeScript project with Jest, ESLint and a lockfile |
| `mixed-monorepo/` | npm workspaces with a Python API and a React app, Docker Compose |
| `requirements/ledger.json` | Valid example requirements ledger |
| `readiness-policy.toml` | Example release readiness policy |
| `archonix.toml` | Example repository configuration (restrict-only) |
| `reports/` | Reports generated by running Archonix on `python-service/`, labelled as examples |

Regenerate the reports with `scripts/regenerate_examples.sh` (requires ruff, bandit,
vulture and pytest on PATH).
